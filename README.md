## The codesaur-php Ecosystem

| Package | Description |
| --- | --- |
| **codesaur/container** | PSR-11 dependency injection container |
| **codesaur/router** | Lightweight HTTP router |
| **codesaur/dataobject** | PDO-based database & model layer |
| **codesaur/template** | Minimal template engine |
| **codesaur/http-message** | PSR-7 / PSR-17 HTTP message implementation |
| **codesaur/http-client** | Minimal cURL HTTP client with JSON & MIME email helpers |
| **codesaur/http-application** | PSR-15 HTTP application & middleware runner |
| 🦖 **codesaur/raptor** | Full-featured, multi-tenant CMS & e-commerce framework - JWT + RBAC auth, localization, SQL migrations, and a PSR-7/PSR-15 middleware core |

> The name **Raptor** honors the **Velociraptor**, whose fossils were first unearthed in **Mongolia's Gobi Desert** (1923).

Explore the ecosystem -> **https://github.com/codesaur-php**

Built with a clear philosophy:

- Minimalism over complexity
- Clean, transparent, readable code
- Zero unnecessary dependencies
- Full Mongolian-language documentation
